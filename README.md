# SceneSeek

**Навчальний проєкт: AI-платформа для пошуку відеофутажів.** SceneSeek має допомогти знаходити, переглядати, зберігати й упорядковувати відеоматеріали.

SceneSeek допомагає знаходити потрібні сцени за текстовим описом, а в цільовій версії — також за голосом і зображенням. Результати з доступних медіабібліотек об’єднуються в одну візуальну стрічку, де відео можна переглянути та зберегти до власних папок.

> Поточний GitHub-репозиторій містить Angular-вебоснову з SSR і prerender. Описані нижче продуктові можливості є планом; їх наявність у коді не передбачається, доки вони фактично не реалізовані.

## Для кого

- відеомонтажери;
- автори контенту;
- дизайнери;
- усі, кому потрібно швидко знаходити відеофутажі для творчих проєктів.

## Основний сценарій

1. Користувач описує сцену звичайною мовою.
2. SceneSeek формує пошукові запити та звертається до підключених джерел.
3. Результати нормалізуються, очищуються від дублікатів і показуються в адаптивній візуальній сітці.
4. Користувач переглядає демонстраційні дані про відео, а потім додає матеріал до вподобаних або папки.

Пошук має запускатися одразу, без обов’язкового уточнення в AI-чаті. Чат може допомагати уточнювати вже запущений пошук.

## Поточний стек репозиторію

| Частина | Поточна основа |
| --- | --- |
| Web-клієнт | Angular 22, TypeScript, Angular Router |
| Рендеринг | Angular SSR і prerender сторінок під час build |
| Стилі | Tailwind CSS 4; SCSS для структурних токенів; палітри у `src/styles/themes/theme-light.css` і `theme-dark.css` |
| Реактивність | Zoneless Angular та Angular Signals |
| Форми | Signal Forms рекомендовані для нових форм |
| Асинхронні дані | `ngxResource()` з `@wawjs/ngx-core`, коли підходить ресурсна модель |
| Переклади | `@wawjs/ngx-translate`; зараз лише українська, з можливістю додати інші мови пізніше |
| Тема | `ThemeService` з `@wawjs/ngx-ui`; темний режим використовує токени `html[data-mode='dark']` |
| Іконки | Material Symbols Outlined |
| Збірка і розгортання | npm, GitHub Actions, GitHub Pages; публікується `dist/app/browser` |
| Середовище | Node.js 20+, npm 11+ рекомендовано репозиторієм |

Firebase запланований для майбутніх серверних функцій, але ще не інтегрований у код. У репозиторії також поки немає окремого SceneSeek backend, бази даних, Ionic/Capacitor-застосунку чи AI-провайдера.

## Заплановані можливості продукту

- текстовий AI-пошук із запуском без попереднього діалогу;
- Pinterest-подібна адаптивна сітка результатів;
- фільтри, сортування, пагінація та дедуплікація;
- деталі відео з демонстраційними відомостями про автора й джерело;
- гостьовий режим і необов’язкова реєстрація;
- історія пошуку, уподобані та особисті папки;
- власні відео, публікації та спільні папки;
- голосовий і візуальний пошук, AI-чат, персоналізація та пошук точних моментів як можливе подальше розширення.
- демонстраційний розділ SceneSeek Pro у налаштуваннях акаунту без оплат і реальної підписки.

Детальні вимоги та перелік екранів — у [технічному завданні](docs/technical-spec.md).

## Демонстраційні дані

На навчальному етапі використовувати приклади та mock-дані. Підключення зовнішніх відеобібліотек, перевірка ліцензій і комерційних умов не входять у поточний обсяг; до роботи з реальними сторонніми матеріалами це питання потрібно буде повернути.

## Структура репозиторію

За структурою та правилами репозиторію:

```text
.github/workflows/        # автоматичне розгортання
src/
  app/
    layouts/              # спільні макети
    pages/                # сторінки з lazy loading
    feature/              # функціональні модулі та бізнес-логіка
    components/           # спільні компоненти
    services/             # спільні сервіси
  assets/
  data/
  environments/
  i18n/                   # переклади
  styles/
    _theme.scss           # спільні структурні токени
    themes/
      theme-light.css    # світла шампаньово-бордова палітра
      theme-dark.css     # темна еспресо-бордова палітра
  styles.scss             # глобальна точка входу стилів
tools/seo/                # SEO-інструменти
angular.json
package.json
```

Нові сторінки розміщувати в `src/app/pages/` і підключати lazy loading через `src/app/app.routes.ts`. Функції з власною бізнес-логікою та інтеграціями групувати в `src/app/feature/<назва>/`. Орієнтуватися на `AGENTS.md` у репозиторії щодо конкретних правил роботи.

Backend і мобільні каталоги не включені до цієї структури, бо їх ще не підтверджено як частину репозиторію.

## Запуск поточної вебоснови

З кореня репозиторію:

```bash
npm install
npm start
```

Типова адреса локальної версії — `http://localhost:4200`. Production build:

```bash
npm run build
```

Build створює `dist/app/browser` і `dist/app/server`; GitHub Pages публікує prerendered browser-вивід із `dist/app/browser`. Перевіряйте актуальні скрипти в `package.json`.

## Орієнтовна послідовність розробки

Пропозиція на основі ТЗ; це не затверджений графік релізів:

1. **Адаптувати вебоснову:** сторінки, навігацію, теми, переклади та компоненти SceneSeek у поточній Angular-структурі.
2. **Пошуковий потік:** текстовий пошук і результати; погодити API-контракт та дозволений спосіб підключення перших медіаджерел.
3. **Бібліотека користувача:** історія, уподобані й папки; до реалізації визначити сховище даних і спосіб авторизації.
4. **Розширення:** деталі відео, голосовий і візуальний пошук, AI-чат, точні моменти, спільні папки, публікації та Pro — після визначення потрібної серверної й мобільної архітектури.

Це навчальний проєкт; зараз готуємо демонстраційний вебзастосунок, а не MVP для запуску.

## Відкриті архітектурні рішення

- навчальний обсяг демонстраційного вебзастосунку;
- чи потрібен окремий мобільний клієнт на Ionic/Capacitor;
- чи буде backend окремим сервісом і де він розміщуватиметься;
- які Firebase-сервіси використовувати: Authentication, Firestore або Realtime Database, Storage чи Cloud Functions;
- чи потрібен окремий FastAPI API поряд із Firebase;
- AI-провайдер і моделі;
- рішення про зовнішні джерела відео для майбутнього етапу;
- демонстраційний вміст розділу Pro без цін, оплат і реального керування підпискою;
- середовища розгортання, секрети, резервне копіювання та CI/CD для майбутніх сервісів.

## Правила роботи з контентом

Демонстраційний контент позначайте як прикладовий. У поточній навчальній версії не підключайте реальні бібліотеки та не реалізуйте завантаження сторонніх матеріалів.
