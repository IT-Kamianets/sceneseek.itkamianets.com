# Підключення Coverr

Coverr використовується як одне з джерел відео SceneSeek. API-ключ не додається до браузерного коду чи Git: локальний Angular dev-сервер отримує його зі змінної середовища, а опублікований сайт звертається до Firebase Function із секретом у Secret Manager.

## Створення API-ключа

1. Увійдіть або створіть акаунт на [Coverr](https://coverr.co/).
2. Відкрийте [Coverr Developers](https://coverr.co/developers) і створіть застосунок.
3. Скопіюйте API-ключ для статусу Demo.

Demo має ліміт 50 запитів на годину й призначений, зокрема, для особистого користування та прототипування. Безкоштовний API вимагає показувати посилання на Coverr і на профіль автора, коли його надано. SceneSeek виводить ці відомості у вікні перегляду відео.

## Запуск у Windows PowerShell

У PowerShell перейдіть до кореня проєкту, задайте ключ для поточного вікна та запустіть застосунок:

```powershell
$env:COVERR_API_KEY = 'вставте-свій-ключ'
npm start
```

Змінна діє лише в цьому вікні PowerShell. Не вставляйте ключ у файли Angular, `environment.ts`, README чи повідомлення й не додавайте його до Git. Якщо закриєте PowerShell, введіть команду з ключем знову.

Пошукові запити в локальному режимі йдуть через `tools/coverr-proxy.cjs`, який передає ключ у заголовку запиту до Coverr. Для опублікованої версії окремо розгорніть Firebase Function за [інструкцією](firebase-setup.md#deploy-the-coverr-proxy); статична публікація GitHub Pages сама функцію не розгортає.

Якщо ключ не заданий або Coverr тимчасово не відповідає, SceneSeek показує результати Wikimedia Commons і повідомляє про недоступність Coverr.

Перегляньте актуальні [умови Coverr API та ліцензії](https://coverr.co/license) перед використанням матеріалів поза прототипом.
